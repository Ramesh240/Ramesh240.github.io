# rameshm.com

Personal portfolio site: skills for recruiters, apps with their own pages and privacy policies, projects, and a blog. Plain static HTML, CSS and JavaScript, generated by one dependency-free Node script.

## Run it

```bash
node build.mjs        # writes the site to dist/
npx serve dist        # preview at http://localhost:3000
```

Needs Node 18 or newer. There is nothing to install.

## Where things live

| Path | What it holds |
| --- | --- |
| `src/data/site.json` | Name, links, track record, experience, education, certifications |
| `src/data/skills.json` | Skill groups, each skill with where you used it |
| `src/data/projects.json` | Flip-card projects (problem on the front, solution on the back) |
| `src/data/apps.json` | Apps: pitch, features, links, privacy facts |
| `src/posts/*.md` | Blog posts, one Markdown file each |
| `src/assets/` | CSS, JavaScript, favicon, social share image |
| `src/static/CNAME` | Custom domain file |
| `build.mjs` | Builds every page, the sitemap, robots.txt and the RSS feed |

## Everyday tasks

**Add an app.** Add an entry to `src/data/apps.json` (copy Foliant's). Fill `links.web` and `links.android` when the app has live links; the buttons appear automatically. The app page, the Apps gallery, the home page highlight, the sitemap and a privacy page are all generated. If the app collects data, create `src/privacy/<slug>.md` with its policy, otherwise the build stops and tells you.

**Add a blog post.** Create `src/posts/my-post.md`:

```
---
title: My post title
date: 2026-11-01
description: One sentence for search results and link previews.
tags: Azure, .NET
---

Post body in Markdown. Use ## for headings.
```

Add `draft: true` to hide a post until it is ready.

**Add a project.** Add an entry to `src/data/projects.json`.

**Update the skills or experience.** Edit `site.json` and `skills.json`.

## Deploy with GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds the site and publishes `dist/` to <https://ramesh240.github.io/> whenever changes are pushed to `main`.

In the repository, open **Settings > Pages** and set **Build and deployment > Source** to **GitHub Actions**. The deployed `CNAME` file configures `rameshm.com` as the custom domain; enable **Enforce HTTPS** after GitHub makes it available.

## Point rameshm.com at it (Spaceship DNS)

In Spaceship, open the `rameshm.com` domain's **DNS records** and add the GitHub Pages records:

| Type | Host | Value |
| --- | --- | --- |
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | Ramesh240.github.io |

GitHub Pages may instead show domain-specific DNS instructions in **Settings > Pages**; follow those if they differ. DNS changes can take from a few minutes to a few hours.

## Later: apps with a backend

Keep this site on GitHub Pages. Host each backend app on Vercel or Netlify and attach a subdomain such as `app-name.rameshm.com` with one CNAME record at Spaceship. Subdomains cost nothing. Add the app to `apps.json` so it gets its page here, and write its own privacy policy before it collects any data.

## Things to review before launch

- **Foliant links.** `links.web` and `links.android` in `apps.json` are empty. Add your live links; until then the page shows GitHub and email only.
- **Screenshots.** The app page uses an illustration. Add real screenshots when you have them.
- **Privacy policies.** They are plain-language drafts based on Foliant collecting no data. Read them against what each app really does and the rules of each app store.
- **Fonts.** Pages load Bricolage Grotesque and Source Serif 4 from Google Fonts, and the site-wide privacy policy says so. To remove that dependency, download the fonts, host them in `src/assets/` and update the `<link>` in `build.mjs`.
- **Sample posts.** The three posts are drafts for you to edit in your own voice.
- **Employer wording.** Experience says "Fortune 50 healthcare retail client" and does not name your employer, matching your current site. Add it in `site.json` if you want it shown.
- **Resume.** The Skills page has a "Request my resume" email button, and prints cleanly to PDF from the browser.
